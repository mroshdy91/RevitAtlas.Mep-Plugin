# Atlas MEP

Scoped Revit 2025/2026 native MEP project work with Atlas Core.

Version 2.0.0-alpha.3 is a scoped public alpha for Revit 2025/2026 on Windows x64. Install Atlas Core and the desired specialists from Atlas Marketplace. Core supplies one shared, pinned runtime; specialists add client surfaces and guidance. Ask your agent to set up RevitAtlas and check the connection. Licensed Revit is required.

Read [release scope](RELEASE-READINESS.md), [client routes](CLIENTS.md) and [free use terms](FREE-USE-TERMS.txt). Available tools exceed the qualified scenario set. MEP admission is limited to the actions and native domains in RELEASE-READINESS.json. Mechanical, electrical and spatial work, project drawings and saved RVT verification require task-specific review.
